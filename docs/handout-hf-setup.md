# 受講者向けの事前準備：Hugging Faceのアカウント設定

このセミナーの発展編Cで、SAM 3D Body（Meta社の大きなAIモデル）を無料のGoogle Colabで動かしてみたい方のための準備手順です。
プログラミングの経験がなくても、この手順のとおりに進めれば準備できます。

> 本編の実習ノートと、発展のノート（MediaPipeを使うもの）には、この準備は要りません。
> 自分のスマホ動画も、本編の実習ノートで測れます。
> 発展のノートC（`02_sam3d_body.ipynb`）を動かしたい方だけ進めてください。

## 用語のかんたんな説明

- Hugging Face（ハギングフェイス）：AIモデル（今回使うSAM 3D Bodyというソフトウェアの中身）を配布しているWebサイトです。
- ゲート付きモデル：無料で使えるものの、事前に申請ボタンを押す必要があるモデルです。利用者が「使う目的」に同意したことを確かめるために、申請を求めています。
- アクセストークン：Hugging Faceのサイトが発行する文字列で、あなたの代わりにパスワードのように使います。Google Colabに貼り付けて使います。

## 手順1：Hugging Faceのアカウントを作る

1. https://huggingface.co/join にアクセスします。
2. メールアドレス・パスワード・ユーザー名を入力して「Sign Up」を押します。
3. 登録したメールアドレスに確認メールが届きます。メールの中のリンクをクリックして、認証を済ませてください。
4. サイトの右上にご自身のアイコンが出れば、ログインできています。

## 手順2：`facebook/sam-3d-body-dinov3`の利用申請をする

1. ログインした状態で https://huggingface.co/facebook/sam-3d-body-dinov3 を開きます。
2. モデル名のすぐ下あたりに「Gated model」という表示と、利用規約への同意ボタンがあります。ボタンの表示は、ふつう「Agree and access repository」などです。内容を確かめ、ボタンを押して申請します。
3. 申請が承認されると、下の画像のように「Gated model — You have been granted access to this model」という表示に変わります。

   ![sam-3d-body-dinov3の承認済み画面](assets/handout/hf_gate_sam3d_body.jpg)

   > 申請した直後はこの表示にならず、同意用のボタンが出ています。自動で承認される場合は数秒〜数分、審査が入る場合は数時間〜数日かかることがあります。

承認されていることが必須です。審査待ちのままだと、Colabで`403`と「awaiting a review」（審査待ち）というエラーが出て止まります。

## 手順3：アクセストークンを発行する

1. https://huggingface.co/settings/tokens を開きます。パスワードの再入力を求められることがあります。
2. 「Create new token」ボタンを押します。
3. トークンの種類は「Read」（読み取り専用）を選びます。書き込みの権限は要りません。
4. トークン名には分かりやすい名前（例：`pt-seminar-colab`）を入れ、作成します。
5. 表示された文字列（`hf_`で始まる長い文字列）をコピーします。

> 重要な注意：このトークンの全文は一度しか表示されません。安全な場所（パスワード管理アプリなど）に控えておいてください。他人に教えたり、SNSやチャットにそのまま貼り付けたりしないでください。忘れたときは、同じページで新しいトークンを作り直せます。古いトークンは削除できます。

## 手順4：Colabのノートブックにトークンを入力する

発展のノートC（`02_sam3d_body.ipynb`）の「3. Hugging Faceのトークンを貼る」のセルを実行（Shift+Enter）すると、入力欄が出ます。手順3でコピーした`hf_`から始まる文字列を貼り付けて、Enterを押してください。貼った文字は表示されません。

最後に「入ったアカウント:」のあとにユーザー名が出ます。手順2で申請したアカウントと同じか確かめてください。

## 手順5：当日、時間がかかることを知っておく

- ノートを開いたら、メニューの［ランタイム］→［ランタイムのタイプを変更］で「T4 GPU」を選びます。T4は無料のColabでも選べます。
- モデルの重み（約2.8GB）の取得に数分かかります。Colabは閉じると中身が消えるので、使うたびに取り直しになります。
- 正面の動画1本の処理には約5分かかります。
- 無料のColabでは、GPUを使える時間に上限があります。途中で切れたときは、上のセルから押し直してください。

## 手順6：いつまでに準備すればよいか

セミナーの開催日の3日前までに、手順1〜3を済ませてください。

3日前としているのは、承認の待ち時間のためです。ゲート付きモデルの承認は自動ですぐに済む場合もありますが、Meta社の審査が入り、数時間〜数日かかる場合もあります。直前だと当日に間に合わない可能性があります。

## 参考：SAM-Body4D（動画全体を扱うモデル）を試したい方

参考のノート（`00_body4d_inference.ipynb`）は、SAM-Body4Dを動かすノートです。講師が試したところ、無料のT4ではGPUのメモリが足りず止まりました。有料のColabでL4かA100を選ぶ必要がありますが、L4・A100での動作はまだ確かめていません。手順2に加えて https://huggingface.co/facebook/sam3 の利用申請も必要で、重みは合計約24GBです。

## うまくいかないとき

次のどれかがうまくいかないときは、無理に自分で解決しようとせず、講師までご連絡ください。

- Hugging Faceのアカウント作成・メール認証ができない
- モデルの申請ボタンが見つからない、または申請したのに承認されない
- トークンの発行画面が開けない・エラーが出る
- Colabでトークンを入力したあともエラーが出る

連絡先は、セミナーの事前案内メールに書いてある講師の連絡先です。症状のスクリーンショットを添えてご連絡ください。
