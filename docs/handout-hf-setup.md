# 受講者向け事前準備：Hugging Face アカウント設定

このセミナーの「アドバンス編」実習（SAM-Body4D をご自身の動画で動かす体験）に参加希望の方向けの準備手順です。
プログラミング経験がなくても、この手順どおりに進めれば準備できます。

> **本編の実習（ROM評価・リーチング解析）にはこの準備は不要です。**
> 本編は講師が事前に用意したデータをそのまま使うため、この手順書はスキップして構いません。
> アドバンス編（自分の動画をAIに解析させてみる）に挑戦したい方だけ進めてください。

## 用語のかんたんな説明

- **Hugging Face（ハギングフェイス）**：AIモデル（今回使うSAM-Body4Dというソフトウェアの中身）を配布しているWebサイトです。
- **ゲート付きモデル**：無料で使えますが、利用者が「使う目的」に同意したことを確認するため、事前に申請ボタンを押す必要があるモデルです。
- **アクセストークン**：Hugging Faceのサイトが発行する、あなたの代わりにパスワードのように使う文字列です。Google Colab（後述）に貼り付けて使います。

## 手順1：Hugging Face アカウントを作成する

1. https://huggingface.co/join にアクセスします。
2. メールアドレス・パスワード・ユーザー名を入力して「Sign Up」を押します。
3. 登録したメールアドレスに確認メールが届くので、メール内のリンクをクリックして認証を完了します。
4. サイト右上にご自身のアイコンが表示されればログイン完了です。

## 手順2：`facebook/sam3` の利用申請をする

1. ログインした状態で https://huggingface.co/facebook/sam3 を開きます。
2. モデル名のすぐ下あたりに **「Gated model」** という表示と、利用規約への同意ボタン（通常「Agree and access repository」等の表示）があります。内容を確認し、ボタンを押して申請します。
3. 申請が承認されると、下の画像のように **「Gated model — You have been granted access to this model」** という表示に変わります。

   ![sam3の承認済み画面](assets/handout/hf_gate_sam3.jpg)

   > 申請直後はこの表示にならず、代わりに同意用のボタンが出ています。ボタンを押すとこの承認済み表示に変わります（自動承認の場合は数秒〜数分、審査が入る場合は数時間〜数日かかることがあります）。

## 手順3：`facebook/sam-3d-body-dinov3` の利用申請をする

1. 同様に https://huggingface.co/facebook/sam-3d-body-dinov3 を開きます。
2. 手順2と同じように、利用規約に同意して申請します。
3. 承認されると同じく「You have been granted access to this model」の表示になります。

   ![sam-3d-body-dinov3の承認済み画面](assets/handout/hf_gate_sam3d_body.jpg)

**両方のモデルで承認されていることが必須です。** どちらか片方でも未承認だと、Colabでの実行時に `403 Forbidden`（アクセス拒否）というエラーで止まります。

## 手順4：アクセストークンを発行する

1. https://huggingface.co/settings/tokens を開きます（パスワードの再入力を求められることがあります）。
2. 「Create new token」ボタンを押します。
3. トークンの種類は **「Read」**（読み取り専用）を選びます。書き込み権限は不要です。
4. トークン名は分かりやすいもの（例：`pt-seminar-colab`）を入力し、作成します。
5. 表示された文字列（`hf_` で始まる長い文字列）をコピーします。

> **重要な注意：** このトークンは一度しか全文表示されません。安全な場所（パスワード管理アプリなど）に控えておいてください。他人に教えたり、SNSやチャットにそのまま貼り付けたりしないでください。忘れた場合は同じページで新しいトークンを作り直せます（古いトークンは削除できます）。

## 手順5：Colab のノートブックにトークンを入力する

アドバンス編のノートブック（`00_body4d_inference.ipynb`）を開くと、次のようなセルがあります。

```python
# 実行するとトークン入力用のUIが表示される。
# facebook/sam3 と facebook/sam-3d-body-dinov3 の両方でゲート承認済みのアカウントの
# トークン（Read権限で可）を貼り付けること。未承認の場合は次のチェックポイント取得セルで
# 403 Forbidden になる（セル11参照）。
from huggingface_hub import login

login()
```

このセルを実行（Shift+Enter）すると、トークンを貼り付ける入力欄が表示されます。手順4でコピーした `hf_` から始まる文字列を貼り付けてください。

> このノートブックはColab上での動作検証が完了していません（講師が検証中です）。当日うまく動かない場合は、講師のデモ実行や配布済みサンプルデータでの実習に切り替えます。

## 手順6：いつまでに準備すればよいか

**セミナー開催日の3日前まで**に手順1〜4を完了させてください。

理由：ゲートモデルの承認は自動で即時に完了する場合もありますが、Meta社側の審査が入り数時間〜数日かかる場合があります。直前だと当日のアドバンス編実習に間に合わない可能性があります。

## うまくいかないとき

以下のいずれかがうまくいかない場合は、無理に自己解決しようとせず講師までご連絡ください。

- Hugging Faceのアカウント作成・メール認証ができない
- どちらかのモデルの申請ボタンが見つからない、または申請したのに承認されない
- トークンの発行画面が開けない・エラーが出る
- Colabでのトークン入力後もエラーが出る

**連絡先：** セミナー事前案内メールに記載の講師連絡先まで、症状のスクリーンショットを添えてご連絡ください。
