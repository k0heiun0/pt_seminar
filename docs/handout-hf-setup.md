# 受講者向け事前準備：Hugging Face アカウント設定

このセミナーの発展編Cで、SAM 3D Body（Meta社の大きなAIモデル）を無料の Google Colab で動かしてみたい方向けの準備手順です。
プログラミング経験がなくても、この手順どおりに進めれば準備できます。

> **本編の実習ノートと、発展のノート（MediaPipeを使うもの）には、この準備は不要です。**
> 自分のスマホ動画も、本編の実習ノートで測れます。
> 発展のノートC（`02_sam3d_body.ipynb`）を動かしたい方だけ進めてください。

## 用語のかんたんな説明

- **Hugging Face（ハギングフェイス）**：AIモデル（今回使うSAM 3D Bodyというソフトウェアの中身）を配布しているWebサイトです。
- **ゲート付きモデル**：無料で使えますが、利用者が「使う目的」に同意したことを確認するため、事前に申請ボタンを押す必要があるモデルです。
- **アクセストークン**：Hugging Faceのサイトが発行する、あなたの代わりにパスワードのように使う文字列です。Google Colab（後述）に貼り付けて使います。

## 手順1：Hugging Face アカウントを作成する

1. https://huggingface.co/join にアクセスします。
2. メールアドレス・パスワード・ユーザー名を入力して「Sign Up」を押します。
3. 登録したメールアドレスに確認メールが届くので、メール内のリンクをクリックして認証を完了します。
4. サイト右上にご自身のアイコンが表示されればログイン完了です。

## 手順2：`facebook/sam-3d-body-dinov3` の利用申請をする

1. ログインした状態で https://huggingface.co/facebook/sam-3d-body-dinov3 を開きます。
2. モデル名のすぐ下あたりに **「Gated model」** という表示と、利用規約への同意ボタン（通常「Agree and access repository」等の表示）があります。内容を確認し、ボタンを押して申請します。
3. 申請が承認されると、下の画像のように **「Gated model — You have been granted access to this model」** という表示に変わります。

   ![sam-3d-body-dinov3の承認済み画面](assets/handout/hf_gate_sam3d_body.jpg)

   > 申請直後はこの表示にならず、代わりに同意用のボタンが出ています。自動承認の場合は数秒〜数分、審査が入る場合は数時間〜数日かかることがあります。

**承認されていることが必須です。** 審査待ちのままだと、Colabで `403` と「awaiting a review」（審査待ち）というエラーで止まります。

## 手順3：アクセストークンを発行する

1. https://huggingface.co/settings/tokens を開きます（パスワードの再入力を求められることがあります）。
2. 「Create new token」ボタンを押します。
3. トークンの種類は **「Read」**（読み取り専用）を選びます。書き込み権限は不要です。
4. トークン名は分かりやすいもの（例：`pt-seminar-colab`）を入力し、作成します。
5. 表示された文字列（`hf_` で始まる長い文字列）をコピーします。

> **重要な注意：** このトークンは一度しか全文表示されません。安全な場所（パスワード管理アプリなど）に控えておいてください。他人に教えたり、SNSやチャットにそのまま貼り付けたりしないでください。忘れた場合は同じページで新しいトークンを作り直せます（古いトークンは削除できます）。

## 手順4：Colab のノートブックにトークンを入力する

発展のノートC（`02_sam3d_body.ipynb`）の「3. Hugging Face のトークンを貼る」のセルを実行（Shift+Enter）すると、入力欄が出ます。手順3でコピーした `hf_` から始まる文字列を貼り付けて、Enter を押してください。貼った文字は表示されません。

最後に「入ったアカウント:」のあとにユーザー名が出ます。手順2で申請したアカウントと同じか確かめてください。

## 手順5：当日、時間がかかることを知っておく

- ノートを開いたら、メニューの［ランタイム］→［ランタイムのタイプを変更］で「T4 GPU」を選びます（無料の Colab で選べます）。
- モデルの重み（約2.8GB）の取得に数分かかります。Colabは閉じると中身が消えるので、使うたびに取り直しになります。
- 正面の動画1本の処理に約5分かかります。
- 無料のColabはGPUを使える時間に上限があります。途中で切れたときは、上のセルから押し直してください。

## 手順6：いつまでに準備すればよいか

**セミナー開催日の3日前まで**に手順1〜3を完了させてください。

理由：ゲートモデルの承認は自動で即時に完了する場合もありますが、Meta社側の審査が入り数時間〜数日かかる場合があります。直前だと当日に間に合わない可能性があります。

## 参考：SAM-Body4D（動画全体を扱うモデル）を試したい方

参考のノート（`00_body4d_inference.ipynb`）は、SAM-Body4D を動かします。こちらは無料の T4 ではGPUのメモリが足りず止まりました（講師が試した結果）。有料のColabで L4 か A100 を選ぶ必要があり、L4・A100での動作はまだ確かめていません。手順2に加えて https://huggingface.co/facebook/sam3 の利用申請も必要で、重みは合計約24GBです。

## うまくいかないとき

以下のいずれかがうまくいかない場合は、無理に自己解決しようとせず講師までご連絡ください。

- Hugging Faceのアカウント作成・メール認証ができない
- モデルの申請ボタンが見つからない、または申請したのに承認されない
- トークンの発行画面が開けない・エラーが出る
- Colabでのトークン入力後もエラーが出る

**連絡先：** セミナー事前案内メールに記載の講師連絡先まで、症状のスクリーンショットを添えてご連絡ください。
